# 🧬 GroupDNA – WhatsApp Group Chat Analyzer

GroupDNA is a Python-based WhatsApp Group Chat Analyzer that extracts meaningful insights from a WhatsApp chat export.

Instead of looking at a group chat as just a collection of messages, GroupDNA analyzes the conversation to identify activity patterns, participant statistics, frequently used words, response patterns, and personality archetypes.

## 📌 Features

- 💬 WhatsApp chat parsing
- 👥 Participant-wise message analysis
- 📊 Group overview and statistics
- 📅 Most active day and hour
- 🔥 Activity analysis using NumPy
- 🔤 Top frequently used words
- ⏱️ Response time analysis
- 🤫 Silent streak detection
- 🎭 Personality archetypes
- 📋 Final GroupDNA report

## 🛠️ Technologies Used

- Python
- NumPy
- Google Colab
- File Handling
- Dictionaries and Lists
- Loops and Conditional Statements
- `datetime`
